## Build with Lovable

Open your project in the [Lovable editor](https://lovable.dev) and keep building.

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Nightmare AI — Site owner setup

The site owner gets unlimited credits and access to the Admin dashboard. No owner email or password is stored in the code.

1. In Lovable, open **Project Settings → Secrets** and add a secret named `OWNER_SETUP_TOKEN`.
2. For its value, choose a long private random string (20+ characters). Never share it publicly.
3. Sign in to the site, open **Account**, enter that value in **Site Owner Setup** and click **Claim Owner**.
4. Click **Open Admin Dashboard**. Ownership can be claimed only once; afterwards the claim form is hidden.
